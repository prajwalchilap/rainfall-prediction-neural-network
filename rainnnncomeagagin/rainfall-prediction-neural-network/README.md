# Rainfall Prediction Using Neural Networks

A machine learning project for predicting whether rainfall will occur one week ahead using environmental and spatial features.

## Project Overview

This project treats rainfall forecasting as a supervised binary classification problem. A neural network predicts the binary target `rain_next_week`, where the target indicates whether rainfall meets the specified threshold during the following 7-day period.

The preprocessing pipeline works with environmental weather variables, aggregates observations to daily statistics, merges the variables, handles missing values and duplicates, calculates spatial distance to a centroid, creates the week-ahead target, performs a chronological train/validation/test split, scales the selected features, and trains a TensorFlow/Keras feedforward neural network.

## Features

The model uses 9 input features:

- `Tair_f_inst_mean` — air temperature
- `Qair_f_inst_mean` — specific humidity
- `Psurf_f_inst_mean` — surface pressure
- `LWdown_f_tavg_mean` — downward longwave radiation
- `SWdown_f_tavg_mean` — downward shortwave radiation
- `Wind_f_inst_mean` — wind speed
- `TVeg_tavg_mean` — vegetation transpiration
- `AvgSurfT_inst_mean` — average surface temperature
- `dist_to_centroid` — Haversine distance from each location to the dataset centroid

The rainfall label uses the threshold:

`Rainf_tavg_mean >= 2.78 × 10^-5`

The week-ahead label is generated by shifting rainfall by 7 days within each latitude/longitude pair.

## Model Architecture

The final neural network is a feedforward binary classifier:

```text
Input: 9 features
        ↓
Dense(64, ReLU)
        ↓
Dropout(0.3)
        ↓
Dense(32, ReLU, L2=0.01)
        ↓
Dropout(0.3)
        ↓
Dense(1, Sigmoid)
```

Training configuration:

| Parameter | Value |
|---|---|
| Hidden layers | 2 |
| Neurons | 64, 32 |
| Hidden activation | ReLU |
| Output activation | Sigmoid |
| Dropout | 0.3 |
| Optimizer | Adam |
| Learning rate | 0.001 |
| Loss | Binary cross-entropy |
| Batch size | 32 |
| Maximum epochs | 50 |
| Early stopping patience | 5 |
| L2 regularization | 0.01 on second hidden layer |

## Data Split

A chronological split is used to avoid training on future observations:

| Split | Period | Rows |
|---|---|---:|
| Training | March–November 2024 | 3,835,227 |
| Validation | December 2024 | 469,929 |
| Test | January–February 2025 | 788,268 |

The final week-ahead dataset contains 5,093,424 rows and 42 columns, covering 15,159 unique latitude/longitude pairs.

## Results

Reported test-set performance:

| Metric | Score |
|---|---:|
| Accuracy | 73.34% |
| Precision | 27.01% |
| Recall | 90.01% |
| F1 Score | 41.56% |
| ROC-AUC | ~0.80 |

The model achieves high recall, meaning it captures most of the rainfall events in the test set. Precision is substantially lower, reflecting the false-positive trade-off associated with the class imbalance described in the accompanying report.

The repository includes the test predictions in `results/test_predictions.csv`.

## Dataset

The original weather dataset consisted of 132 CSV files covering March 2024 to February 2025 across 11 weather variables.

The raw dataset is **not included in this repository** because of its size. To reproduce the complete pipeline, place the original CSV files in a local input directory following the filename convention used by the source script.

The script has been cleaned so that local input/output paths are configurable rather than tied to a specific Windows user directory.

## Installation

Python 3.10+ is recommended.

```bash
python -m venv .venv
```

Windows:

```bash
.venv\Scripts\activate
```

macOS/Linux:

```bash
source .venv/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

## Running the Project

Set the input and output directories in:

```text
src/machine_learning_rain_prediction.py
```

Then run:

```bash
python src/machine_learning_rain_prediction.py
```

The complete preprocessing and model-training pipeline works with the original raw weather CSV files. Because the raw dataset is very large, execution time and memory requirements can be substantial.

## Results and Report

The accompanying report is available at:

`report/MACHINE_LEARNING.pdf`

The report documents the preprocessing pipeline, feature engineering, neural network architecture, training configuration, evaluation metrics, and data split.

## Important Reproducibility Note

The reported metrics are based on the completed run documented in the report. Re-running the neural network can produce slightly different results unless random seeds and the exact computational environment are controlled.
